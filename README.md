## Development of a Weather Forecast Notifier Using Telegram

Python과 OpenWeatherMap API, Telegram Bot API를 활용하여
실시간 날씨 예보를 텔레그램으로 자동 전송하는 프로그램입니다.

## Overview

본 프로젝트는 OpenWeatherMap API를 통해 날씨 예보 데이터를 수집하고,
Telegram Bot API를 이용하여 사용자에게 자동으로 날씨 정보를 전달하는 프로그램입니다.

## OpenWeatherMap API 기반 날씨 예보 수집
Telegram Bot 메시지 자동 전송
asyncio 기반 반복 실행
지정 시간 자동 알림 기능
Tech Stack
Python 3.x
OpenWeatherMap API
Telegram Bot API
urllib
json
asyncio
System Structure

## Features

- 서울 지역 날씨 예보 조회  
- 온도 / 습도 / 날씨 상태 출력  
- Telegram 메시지 자동 전송  
- 지정 시간 알림 기능  
- asyncio 기반 반복 실행
